# Student Training and Trainer Allocation Management System

## Project Overview
A Python OOP-based application that manages student registration and trainer allocation. It allows users to select courses, choose suitable trainers and available timings, view course durations, and generate a summary of student assignments.

## Features
- Register multiple students.
- Select courses and trainers.
- Choose preferred training timings.
- Display course duration and assignment details.
- Generate a final student assignment summary.
- Validate user inputs.

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Lists and Dictionaries
- Exception Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python3 training_system.py
```
